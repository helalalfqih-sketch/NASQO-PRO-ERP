Android uses the bundled React shell in every build. The extra Flutter toolbar is restricted to historical review, where exit and recovery actions remain available. Google identity can be connected from React system settings, separately from the local workspace. Native Drive uses drive.file authorization and exposes only connection, disconnection, account metadata and file listing. Tokens stay native. Drive backup upload/download and changes are not enabled; local backup is the supported workflow. Physical-device OAuth, consent, and API availability still require testing. No cloud resources or permissions are changed by this commit.
