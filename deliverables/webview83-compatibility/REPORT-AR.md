# توافق واجهة Android مع WebView 83

البدء من نسخة العمل الحالية 626479321d459a90c000546da4f81ed7691ca141، مع الاحتفاظ بتغييرات Bitrise والتقارير السابقة. فرع النشر لم يتغير.

أُعيد إنتاج الشاشة الفارغة في APK 1.0.141 على emulator-5554 الذي يستخدم WebView 83.0.4103.106. احتوى ملف JS الفعلي على ||=، وهي صيغة تبدأ في Chrome 85. نافذة تعطل System UI سابقة ومستقلة عن هذا الخلل.

الإصلاح يحدد هدف JS إلى ES2020/Chrome 83 وهدف CSS إلى Chrome 83، ويفحص كل ملف JavaScript ناتج بالمحلل قبل اعتماد الحزمة. أُزيل استخدام Array.at من رد الرجوع ومعاينة مرجع الفاتورة، مع إبقاء الدلالات والمبالغ كما هي. لم تتغير الحزمة أو الشهادة أو منطق الترحيل.

التحقق المحلي: فحص 28 ملفًا محميًا، بناء 64 أصلًا محليًا واجتياز فحص الصياغة وسياسة العمل دون شبكة، و48 اختبار JavaScript، و8 اختبارات رجوع اصطناعية بعد حذف Array.at من بيئة المتصفح. لا تمثل اختبارات المتصفح قبولًا على Android.

يبقى فحص الحزمة الموقعة والترقية وظهور الرئيسية والتنقل على WebView 83 قيد التنفيذ. ستضاف النتيجة الفعلية ومعرف البناء وSHA المصدر وبصمة APK هنا بعد انتهاء الاختبار. لا نشر إنتاج ولا دمج في فرع النشر ضمن هذه الدفعة.
